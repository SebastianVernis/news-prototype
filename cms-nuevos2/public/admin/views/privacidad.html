Política de Privacidad

Información legal sobre el uso de datos en NexoPress.

NexoPress

Última actualización: 24 de febrero de 2026

1. Introducción

NexoPress es una plataforma privada de gestión editorial y automatización de publicaciones digitales, desarrollada y operada por Sebastian Vernis.

La aplicación permite gestionar y publicar contenido en páginas de Facebook administradas por el titular del sistema. NexoPress no está diseñada como aplicación de consumo público ni recopila datos personales de usuarios finales.

2. Información que Recopilamos

NexoPress no recopila datos personales de usuarios de Facebook ni de terceros. La aplicación únicamente accede a la siguiente información técnica, necesaria para su funcionamiento:

  • Identificador de páginas administradas
  • Tokens de acceso otorgados por Meta
  • Permisos de publicación y gestión de páginas
  • Información básica de las páginas administradas

No se recopilan: Datos de perfil, listas de amigos, mensajes privados, información sensible ni datos financieros.

3. Uso de la Información

La información obtenida a través de la API de Meta se utiliza exclusivamente para publicar artículos en páginas administradas, gestionar contenido editorial y registrar métricas técnicas internas. La información no se vende, alquila ni comparte con terceros.

4. Almacenamiento y Seguridad

Los tokens de acceso y credenciales se almacenan de manera segura en infraestructura protegida. Se aplican medidas técnicas razonables para prevenir accesos no autorizados o pérdida de información. El acceso está restringido al administrador autorizado.

5. Compartición de Datos

NexoPress no comparte información con terceros. La única transmisión de datos ocurre directamente entre la aplicación y la plataforma Meta, utilizando las APIs oficiales.

6. Retención de Datos

La aplicación conserva únicamente registros técnicos de publicaciones e identificadores necesarios para auditoría interna. No se almacenan datos personales de usuarios finales de Facebook.

7. Eliminación de Datos

Si un administrador revoca los permisos desde su cuenta de Facebook, el acceso será eliminado. Para solicitar la eliminación de datos técnicos, escriba a: contacto@sebastianvernis.space

8. Derechos de los Usuarios

Dado que no se recopilan datos personales de usuarios finales, no se gestionan solicitudes de acceso, rectificación o eliminación de los mismos.

9. Cambios en esta Política

Esta Política puede actualizarse en cualquier momento. Las modificaciones serán publicadas en esta misma página.
