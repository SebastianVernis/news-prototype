# 🚀 Portal NexoPress

Portal de selección de CMS para gestionar los 27 sitios de noticias.

## 📍 URL
https://nexopress.sebastianvernis.space

## 🎯 Funcionalidad
- Visualización de los 3 CMS disponibles
- Logos de todos los sitios para fácil identificación
- Acceso directo a cada panel de administración
