# Scripts Index

- `build/`: Build helpers.
- `deploy/`: Deployment flows for Pages/Workers and multi-site publishing.
- `run/`: Runtime helpers (cron wrappers).
- `setup/`: Installation and environment setup.
- `templates/`: CSS template generators.
- `verify/`: Verification and health checks.

Use `SITES_DIR`, `NEWS_DATA_DIR`, and `NEWS_ASSETS_DIR` env vars to override default paths.
