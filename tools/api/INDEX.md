# API Tools

- `newsapi.py`, `newsdata.py`, `worldnews.py`, `apitube.py`: API ingestion scripts.
- `paraphrase.py`, `gemini_paraphraser.py`, `hybrid_paraphraser.py`, `linguistic_paraphraser.py`: Paraphrasing variants.
- `generate-images-ai.py`: AI image generation.
- `update_api_images.py`: Update API image references.
- `r2_image_manager.py`: R2 image upload manager.
