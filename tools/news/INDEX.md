# News Tools

- `master-news-flow.py`: Orchestrates full pipeline across tools.
- `ai_multi_source_publish_flow.py`: 3 APIs -> OpenRouter ranking -> 3-source synthesis -> 1200-word article -> D1 publish.
- `news-flow-complete.py`: End-to-end pipeline with images and deploy.
- `news-publisher.py`: Automated publishing scheduler.
- `news-management-system.py`: Combined news ingestion + API updates.
- `newsapi.py`, `news.py`: News fetchers.
- `paraphrase.py`: Paraphrasing utility.
- `complete-and-add-news.py`, `complete-articles.py`: Post-process articles.
