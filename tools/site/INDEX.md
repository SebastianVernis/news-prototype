# Site Tools

- `generate-sites.py`: Generates static site HTML.
- `create-complete-structure.py`: Builds categories and legal pages.
- `update-sites-names.py`: Applies site naming and taglines.
- `update-css-references.py`: Fixes template CSS links.
- `add-responsive-css.py`: Adds responsive styles.
- `fix-html-structure.py`: Repairs HTML structure issues.
- `fix-site-links.py`: Cleans invalid links.
- `update-images-preloaders.py`: Injects preloaders and carousels.
